NIVORA — ഉപയോഗ നിബന്ധനകൾ

അവസാനം പുതുക്കിയത്: 5 നവംബർ 2026

NIVORA 21–40 വയസ്സുള്ള മുതിർന്നവർക്കുള്ള കേരള കേന്ദ്രീകൃത പരിചയപ്പെടൽ സേവനമാണ്. ഇത് വ്യക്തിഗത ഓപ്പറേറ്ററായ Sebastian Thomas ആണ് നടത്തുന്നത്; നിലവിൽ രജിസ്റ്റർ ചെയ്ത കമ്പനിയില്ല. ബന്ധപ്പെടാൻ nivora.helpdesk@gmail.com.

1. യോഗ്യത

അംഗമാകാൻ 21–40 വയസ്സിനിടയിൽ ആയിരിക്കണം. Google account വഴിയാണ് പ്രവേശനം. വയസ്സ് ഉപയോക്താവ് സ്വയം നൽകുന്നതാണ്; NIVORA അത് സ്വതന്ത്രമായി പരിശോധിക്കുന്നില്ല. ശരിയായ വിവരങ്ങൾ മാത്രം നൽകുക; മറ്റൊരാളായി നടിക്കുകയോ അനുമതിയില്ലാത്ത ഫോട്ടോ ഉപയോഗിക്കുകയോ അരുത്.

2. സൗജന്യ സേവനം

നിലവിൽ സേവനം സൗജന്യമാണ്. ഓരോ അംഗത്തിനും കേരള കലണ്ടർ ദിവസത്തിൽ പരമാവധി അഞ്ച് matching recommendations ലഭിക്കാം. ഒരു recommendation ഇരുവരുടെയും daily usage-ൽ എണ്ണപ്പെടും. Active സംഭാഷണം പരമാവധി 72 മണിക്കൂർ. Text chat, voice messages മാത്രമാണ്; live voice/video calls ഇല്ല. Match ഉറപ്പുനൽകുന്നില്ല.

3. Shake & Chat, location പങ്കിടൽ

Shake & Chat ഓപ്ഷണൽ ആണ്. നിങ്ങൾ ഇത് enable ചെയ്ത് browser location അനുമതി നൽകിയാൽ, 50 km ചുറ്റളവിൽ ഇതേ സൗകര്യം enable ചെയ്ത അനുയോജ്യരായ അംഗങ്ങളെ കണ്ടെത്താൻ NIVORA location ഉപയോഗിക്കും. മറ്റുള്ളവർക്ക് ഏകദേശ ദൂരം മാത്രമേ കാണൂ; കൃത്യമായ coordinates അല്ലെങ്കിൽ address കാണിക്കില്ല. എപ്പോൾ വേണമെങ്കിലും location sharing off ചെയ്യാം; അപ്പോൾ സൂക്ഷിച്ച location ഇല്ലാതാക്കും. ഒരാൾക്ക് interest അയച്ചതുകൊണ്ട് മാത്രം chat തുറക്കില്ല. ഇരുവരും താൽപര്യം അറിയിച്ചാൽ മാത്രമേ chat തുടങ്ങൂ. Shake & Chat അജ്ഞാതമായാണ് തുടങ്ങുന്നത്: രണ്ടുപേരും സമ്മതിക്കുന്നതുവരെ പേര്, ഫോട്ടോ, profile വിവരങ്ങൾ മറച്ചുവെക്കും. മറ്റേയാൾ സമ്മതിക്കുന്നതിന് മുമ്പ് ഓരോരുത്തർക്കും സ്വന്തം സമ്മതം പിൻവലിക്കാം; ഇരുവരും സമ്മതിച്ചാൽ ആ സംഭാഷണത്തിൽ profile വിവരങ്ങൾ കാണിക്കും. 72 മണിക്കൂർ സംഭാഷണവും safety നിബന്ധനകളും ബാധകമാണ്. മറ്റൊരാളുടെ കൃത്യമായ സ്ഥലം കണ്ടെത്താനോ പിന്തുടരാനോ ഉപദ്രവിക്കാനോ ഈ feature ഉപയോഗിക്കരുത്.

4. അംഗങ്ങളുടെ പെരുമാറ്റം

ഉപദ്രവിക്കൽ, ഭീഷണിപ്പെടുത്തൽ, പിന്തുടരൽ, വിവേചനം, തട്ടിപ്പ്, പണം ആവശ്യപ്പെടൽ, മറ്റൊരാളുടെ സ്വകാര്യവിവരങ്ങൾ അനുമതിയില്ലാതെ പങ്കിടൽ, നിയമവിരുദ്ധമോ ദോഷകരമോ ആയ ഉള്ളടക്കം upload ചെയ്യൽ, security controls മറികടക്കൽ എന്നിവ അനുവദനീയമല്ല. നിങ്ങൾ നൽകുന്ന profile, photo, message എന്നിവയുടെ ഉത്തരവാദിത്തം നിങ്ങളുടേതാണ്.

5. ഉള്ളടക്കം, Report, Block

Report അല്ലെങ്കിൽ Block ചെയ്യാം. Block ചെയ്താൽ ബന്ധപ്പെട്ട സംഭാഷണം അവസാനിക്കുകയും വീണ്ടും matching തടയുകയും ചെയ്യും. Report ലഭിച്ചാൽ NIVORA ബന്ധപ്പെട്ട profile-ഉം ആവശ്യമായ സംഭാഷണ തെളിവുകളും പരിശോധിച്ച് സുരക്ഷാ നടപടി സ്വീകരിക്കാം. Customer profiles സ്വയം active ആകും; profile photos staff അംഗീകരിച്ച ശേഷമേ മറ്റംഗങ്ങൾക്ക് കാണിക്കൂ. Photo approval identity verification അല്ല. നിങ്ങൾ നൽകുന്ന ഉള്ളടക്കത്തിന്റെ ഉടമസ്ഥാവകാശം നിങ്ങളുടേതാണ്; സേവനം പ്രവർത്തിപ്പിക്കാനും സുരക്ഷ ഉറപ്പാക്കാനും ആവശ്യമായ പരിമിത ഉപയോഗാനുമതി NIVORA-യ്ക്ക് നൽകുന്നു.

6. സുരക്ഷ

NIVORA അംഗങ്ങളുടെ identity, വയസ്സ്, ജോലി, background അല്ലെങ്കിൽ പ്രസ്താവനകൾ സ്വതന്ത്രമായി പരിശോധിക്കുന്നില്ല. മറ്റൊരാൾക്ക് പണം അയക്കരുത്. ആദ്യ കൂടിക്കാഴ്ച പൊതുസ്ഥലത്ത് നടത്തുക. അപകടമുണ്ടെങ്കിൽ പ്രാദേശിക emergency services-നെ ബന്ധപ്പെടുക.

7. സ്വകാര്യതയും deletion-ഉം

സ്വകാര്യതാ അറിയിപ്പ് വായിക്കുക. “എന്റെ ഇടം” വഴി data export ചെയ്യാനും account deletion അഭ്യർത്ഥിക്കാനും കഴിയും. നിയമം ആവശ്യപ്പെടുന്ന പരിമിത registration, report, audit രേഖകൾ deletion-ന് ശേഷവും സൂക്ഷിക്കാം.

8. സേവനത്തിലെ മാറ്റങ്ങൾ

സേവനം തടസ്സപ്പെടുകയോ features മാറുകയോ ചെയ്യാം. ഭാവിയിൽ പണമടച്ചുള്ള സൗകര്യങ്ങൾ വന്നാൽ പണം ഈടാക്കുന്നതിന് മുമ്പ് പ്രത്യേക നിബന്ധനകൾ കാണിക്കും. ഇപ്പോഴത്തെ സേവനം സൗജന്യമാണ്.

9. നിയന്ത്രണവും അവസാനിപ്പിക്കലും

നിബന്ധനകൾ ലംഘിച്ചാൽ, സുരക്ഷാ ഭീഷണിയുണ്ടെങ്കിൽ, അല്ലെങ്കിൽ നിയമം ആവശ്യപ്പെട്ടാൽ account നിയന്ത്രിക്കുകയോ suspend ചെയ്യുകയോ ചെയ്യാം. നിങ്ങൾക്ക് സേവനം നിർത്താനും account deletion അഭ്യർത്ഥിക്കാനും കഴിയും.

10. നിയമവും അവകാശങ്ങളും

ഇന്ത്യയിലെ ബാധകമായ നിയമങ്ങൾ അനുസരിച്ചാണ് ഈ നിബന്ധനകൾ. നിയമപ്രകാരം ഒഴിവാക്കാനാവാത്ത ഉപഭോക്തൃ അവകാശങ്ങൾ ഇല്ലാതാക്കുന്നില്ല.
