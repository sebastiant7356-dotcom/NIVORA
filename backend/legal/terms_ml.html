BEYOND — ഉപയോഗ നിബന്ധനകൾ

അവസാനം പുതുക്കിയത്: 7 നവംബർ 2026

BEYOND 18+ വയസ്സുള്ള മുതിർന്നവർക്കുള്ള ലോകമെമ്പാടും ലഭ്യമായ Social Discovery App ആണ്. Shake & Chat, Anonymous Posts, ഇരുവരുടെയും സമ്മതത്തിലുള്ള Friend Connections എന്നിവയാണ് പ്രധാന സൗകര്യങ്ങൾ. ഇത് വ്യക്തിഗത ഓപ്പറേറ്ററായ Sebastian Thomas ആണ് നടത്തുന്നത്; നിലവിൽ രജിസ്റ്റർ ചെയ്ത കമ്പനിയില്ല. ബന്ധപ്പെടാൻ nivora.helpdesk@gmail.com.

1. യോഗ്യത

അംഗമാകാൻ 18+ വയസ്സിനിടയിൽ ആയിരിക്കണം. Google account വഴിയാണ് പ്രവേശനം. വയസ്സ് ഉപയോക്താവ് സ്വയം നൽകുന്നതാണ്; BEYOND അത് സ്വതന്ത്രമായി പരിശോധിക്കുന്നില്ല. ശരിയായ വിവരങ്ങൾ മാത്രം നൽകുക; മറ്റൊരാളായി നടിക്കുകയോ അനുമതിയില്ലാത്ത ഫോട്ടോ ഉപയോഗിക്കുകയോ അരുത്.

2. Shake & Chat

BEYOND നിലവിൽ സൗജന്യമാണ്. അംഗങ്ങൾക്ക് 1–100 km വരെ സ്വന്തം discovery Radius തിരഞ്ഞെടുക്കാം. Location permission നൽകി Shake discovery enable ചെയ്താൽ ലോകമെമ്പാടുമുള്ള മറ്റ് അംഗങ്ങളെ കണ്ടെത്താം. കൃത്യമായ coordinates അല്ലെങ്കിൽ address മറ്റംഗങ്ങൾക്ക് കാണിക്കില്ല. ഇരുവരും interest അറിയിച്ചാൽ anonymous chat തുടങ്ങും. Automatic time limit ഇല്ല. ഇരുവർക്കും chat അവസാനിപ്പിക്കാനോ Block ചെയ്യാനോ കഴിയും. Text chat, voice messages ലഭ്യമാണ്; live voice/video calls ഇപ്പോൾ ലഭ്യമല്ല.

Active chat-ൽ നിന്ന് Friend Request അയയ്ക്കാം. മറുവശത്തുള്ളയാൾ Accept ചെയ്താൽ മാത്രമേ Friendship ഉണ്ടാകൂ. Request അയച്ചതുകൊണ്ട് മാത്രം profile വിവരങ്ങൾ വെളിപ്പെടുത്തില്ല.

3. Profile Privacy, Anonymous Posts

Profile മറ്റുള്ളവർക്ക് കാണിക്കണോ Hidden ആക്കണോ എന്ന് നിങ്ങൾക്ക് തീരുമാനിക്കാം. Hidden profile Shake discovery-ൽ കാണിക്കില്ല. Chat anonymous ആയി തുടങ്ങും; ഇരുവരും സമ്മതിച്ചാൽ മാത്രമേ profile വിവരങ്ങൾ കാണിക്കൂ. Hidden profile-ന്റെ വിവരങ്ങൾ മറഞ്ഞുതന്നെ തുടരും.

Anonymous text post ലോകമെമ്പാടുമുള്ള എല്ലാ BEYOND അംഗങ്ങൾക്കോ നിങ്ങൾ തിരഞ്ഞെടുത്ത nearby Radius-ിലുള്ളവർക്കോ പ്രസിദ്ധീകരിക്കാം. മറ്റംഗങ്ങൾക്ക് നിങ്ങളുടെ profile identity കാണിക്കില്ല. Report, moderation, safety investigation എന്നിവയ്ക്കായി authorised staff-ന് author identity ലഭ്യമായിരിക്കും. ഭീഷണി, ഉപദ്രവം, മറ്റുള്ളവരുടെ personal data, നിയമവിരുദ്ധ ഉള്ളടക്കം എന്നിവ post ചെയ്യരുത്. സ്വന്തം post delete ചെയ്യാം. കൃത്യമായ location കണ്ടെത്താനോ പിന്തുടരാനോ location feature ഉപയോഗിക്കരുത്.

4. അംഗങ്ങളുടെ പെരുമാറ്റം

ഉപദ്രവിക്കൽ, ഭീഷണിപ്പെടുത്തൽ, പിന്തുടരൽ, വിവേചനം, തട്ടിപ്പ്, പണം ആവശ്യപ്പെടൽ, മറ്റൊരാളുടെ സ്വകാര്യവിവരങ്ങൾ അനുമതിയില്ലാതെ പങ്കിടൽ, നിയമവിരുദ്ധമോ ദോഷകരമോ ആയ ഉള്ളടക്കം upload ചെയ്യൽ, security controls മറികടക്കൽ എന്നിവ അനുവദനീയമല്ല. നിങ്ങൾ നൽകുന്ന profile, photo, message എന്നിവയുടെ ഉത്തരവാദിത്തം നിങ്ങളുടേതാണ്.

5. ഉള്ളടക്കം, Report, Block

Report അല്ലെങ്കിൽ Block ചെയ്യാം. Block ചെയ്താൽ ബന്ധപ്പെട്ട സംഭാഷണം അവസാനിക്കുകയും വീണ്ടും matching തടയുകയും ചെയ്യും. Report ലഭിച്ചാൽ BEYOND ബന്ധപ്പെട്ട profile-ഉം ആവശ്യമായ സംഭാഷണ തെളിവുകളും പരിശോധിച്ച് സുരക്ഷാ നടപടി സ്വീകരിക്കാം. Customer profiles സ്വയം active ആകും; profile photos staff അംഗീകരിച്ച ശേഷമേ മറ്റംഗങ്ങൾക്ക് കാണിക്കൂ. Photo approval identity verification അല്ല. നിങ്ങൾ നൽകുന്ന ഉള്ളടക്കത്തിന്റെ ഉടമസ്ഥാവകാശം നിങ്ങളുടേതാണ്; സേവനം പ്രവർത്തിപ്പിക്കാനും സുരക്ഷ ഉറപ്പാക്കാനും ആവശ്യമായ പരിമിത ഉപയോഗാനുമതി BEYOND-യ്ക്ക് നൽകുന്നു.

6. സുരക്ഷ

BEYOND അംഗങ്ങളുടെ identity, വയസ്സ്, ജോലി, background അല്ലെങ്കിൽ പ്രസ്താവനകൾ സ്വതന്ത്രമായി പരിശോധിക്കുന്നില്ല. മറ്റൊരാൾക്ക് പണം അയക്കരുത്. ആദ്യ കൂടിക്കാഴ്ച പൊതുസ്ഥലത്ത് നടത്തുക. അപകടമുണ്ടെങ്കിൽ പ്രാദേശിക emergency services-നെ ബന്ധപ്പെടുക.

7. സ്വകാര്യതയും deletion-ഉം

സ്വകാര്യതാ അറിയിപ്പ് വായിക്കുക. “എന്റെ ഇടം” വഴി data export ചെയ്യാനും account deletion അഭ്യർത്ഥിക്കാനും കഴിയും. നിയമം ആവശ്യപ്പെടുന്ന പരിമിത registration, report, audit രേഖകൾ deletion-ന് ശേഷവും സൂക്ഷിക്കാം.

8. സേവനത്തിലെ മാറ്റങ്ങൾ

സേവനം തടസ്സപ്പെടുകയോ features മാറുകയോ ചെയ്യാം. ഭാവിയിൽ പണമടച്ചുള്ള സൗകര്യങ്ങൾ വന്നാൽ പണം ഈടാക്കുന്നതിന് മുമ്പ് പ്രത്യേക നിബന്ധനകൾ കാണിക്കും. ഇപ്പോഴത്തെ സേവനം സൗജന്യമാണ്.

9. നിയന്ത്രണവും അവസാനിപ്പിക്കലും

നിബന്ധനകൾ ലംഘിച്ചാൽ, സുരക്ഷാ ഭീഷണിയുണ്ടെങ്കിൽ, അല്ലെങ്കിൽ നിയമം ആവശ്യപ്പെട്ടാൽ account നിയന്ത്രിക്കുകയോ suspend ചെയ്യുകയോ ചെയ്യാം. നിങ്ങൾക്ക് സേവനം നിർത്താനും account deletion അഭ്യർത്ഥിക്കാനും കഴിയും.

10. നിയമവും അവകാശങ്ങളും

ഇന്ത്യയിലെ ബാധകമായ നിയമങ്ങൾ അനുസരിച്ചാണ് ഈ നിബന്ധനകൾ. നിയമപ്രകാരം ഒഴിവാക്കാനാവാത്ത ഉപഭോക്തൃ അവകാശങ്ങൾ ഇല്ലാതാക്കുന്നില്ല.
